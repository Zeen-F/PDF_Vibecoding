# 纸间 Paperdesk · PDF_Vibecoding

在 Mac 浏览器中使用的本地 PDF 文献工作台：导入与检索论文、章节目录导航、文字高亮和区域批注、笔记、Markdown 导出。PDF、索引、笔记和批注保存在本机；普通阅读和编辑不调用 AI 服务。可选的 Codex 插件提供文献工具及用户明确共享的阅读选区，交给 Codex 的文字或图片会进入模型请求。

## 开始开发

使用 **Node.js 24+**，推荐 `.nvmrc` 指定的 24 LTS。在仓库目录执行：

```sh
npm ci
npx playwright install chromium
npm run dev
```

打开 **http://127.0.0.1:5173**。开发命令同时启动界面与 API（4318），使用独立的 `.local/dev-data/` 文献库。端口被占用时会报错，请先处理对应进程后重试。

提交前运行完整检查：

```sh
npm run check
```

开发约定见 [CONTRIBUTING.md](CONTRIBUTING.md)，运行参数和测试说明见 [开发指南](docs/development.md)。

使用 VS Code 或兼容编辑器时，可打开 [PDF_Vibecoding.code-workspace](PDF_Vibecoding.code-workspace)，直接使用开发、检查和日常启动任务。

## 日常使用

首次运行或更新代码后，先构建界面：

```sh
npm ci
npm run build
npm start
```

打开 **http://127.0.0.1:4317**。Mac 也可双击 **启动纸间.command**；保持启动窗口运行，结束时按 Control+C。关闭网页不会删除文献库。启动器只在缺少构建产物时自动构建，更新代码后请主动重新运行 `npm run build`。

1. **导入 PDF**：点击导入按钮或拖入一个／多个 PDF，不设固定文件大小上限。相同内容自动去重，同名但内容不同的文件可共存；也可打开原创阅读示例。
2. **阅读与搜索**：搜索正文、笔记和批注中的中英文关键词，点击结果跳转；支持翻页、适合宽度及固定缩放。顶部可收起／展开文献栏，状态在当前浏览器保留；**⌘K** 会自动展开文献栏并聚焦搜索。窄窗口也可收起笔记面板。
3. **章节目录**：点击阅读工具栏“展开目录”，按层级展开或筛选标题，点击章节跳到 PDF 页。优先使用内置书签；没有书签时尝试识别前 40 页内带文字层的目录页。已有文献可直接使用，无需重新导入。窄窗口中点击章节后会收起目录。
4. **高亮与评论**：拖选原文，先核对底部引文预览，再点击“高亮并批注”。支持反向及跨行选文，评论和颜色可以修改，批注可以删除。**Esc** 取消批注弹窗。原 PDF 不会被覆盖。
5. **笔记**：在一个编辑区自由记录，可混用任意语言并输入 Markdown；停止输入约 0.65 秒后自动保存，也可手动保存。显示“已保存到本机”才表示服务端保存完成。失败时保留浏览器草稿，恢复连接后需确认保存成功。
6. **导出 Markdown**：先保存当前笔记，再下载包含标题、原文件名、笔记、引文、评论和页码的 `.md` 文件，可在 Obsidian 等编辑器继续使用。

旧版分栏笔记会在同一编辑区完整显示，两段之间用 Markdown 分隔线连接。仅打开、未修改地保存或导出不会改写旧记录；编辑保存后才统一存储。旧浏览器草稿也会保留两段内容。

扫描件或图表也可以批注：点击工具栏 **“区域批注”**，在页面上拖出矩形，再点击“添加区域批注”查看本地预览、填写评论并保存。支持反向框选；过小的框选不保存，**Esc** 取消选区。批注卡片中的“框选区域”可跳回原页；已保存矩形随缩放和文献栏布局变化保持定位。区域评论可搜索，导出包含页码和归一化区域坐标，但不包含 OCR 引文或区域截图。

目录页印刷页码与 PDF 页数可能不同。应用能确认页码标签或多个章节标题位置时自动映射；无法确认时条目保持不可跳转，请输入“目录页码偏移”并点击“应用偏移”。例如目录印刷页 1 对应 PDF 第 3 页，偏移填 **2**。校正按文献保存在当前浏览器，可用“恢复自动”清除，不修改原 PDF；未映射的罗马页码不能只靠这个数值偏移导航。

## Codex 插件原型

本机服务启动后，运行 `npm run plugin:install` 安装纸间本地插件。插件使用同一份文献库，提供文献列表、指定页文字、明确共享的文字／扫描图选区、笔记读取与追加、Markdown 导出。选区需点击“交给 Codex”；追加笔记需要明确指令。笔记保持一个编辑区，版本冲突时保留草稿并提醒，不静默覆盖。

0.2.0 的 MCP Apps 面板直接显示文献列表和当前 PDF 页，通过插件通道读取本机数据，不再嵌套本机网页。支持翻页、目录、单一笔记区以及主动共享选区；入口和上下文能力仍取决于宿主支持，浏览器版保留完整阅读功能。完整安装、能力边界与验收说明见 [Codex 插件](docs/codex-plugin.md)。

## 数据与备份

| 位置 | 用途 | 提交 Git |
| --- | --- | --- |
| `data/` | 日常使用的正式文献库 | 否 |
| `.local/dev-data/` | 开发文献库 | 否 |
| `.local/` | 本机迁移清单、备份及临时材料 | 否 |
| `public/examples/`、`tests/fixtures/` | 可共享示例和测试材料 | 是 |
| `dist/`、`public/pdf-assets/` | 可重新生成的构建产物 | 否 |

每个文献库包含 `paperdesk.sqlite` 和 `pdfs/`；数据库保存索引、阅读位置、笔记与批注，PDF 保留原始字节。**备份时先正常停止服务，再复制整个文献库目录；恢复时也先停止服务。** 运行中的 SQLite 可能还有 `-wal`、`-shm` 文件，不要只复制数据库主文件。浏览器草稿不能替代正式备份。

首次用区域批注版本打开旧库前，请先按上述方式备份。启动时数据库会在事务中升级到 schema 2，保留旧记录并将既有批注标记为文字批注；迁移失败会回滚，更新版本的数据库不会被降级。需要退回旧程序时，应恢复升级前的完整备份。

服务仅监听本机 `127.0.0.1`。安装依赖和测试浏览器需要联网，准备完成后的阅读、搜索、笔记和 PDF 资源均在本地处理。

## 当前范围

- 文字高亮需要可选文字层；扫描件可阅读、写笔记和框选区域评论，但没有 OCR，不能搜索或选中图片中的文字。加密／权限受限 PDF 暂不支持。
- 目录页识别是有限规则匹配，需要明确目录标题和可提取文字；复杂目录排版可能无法识别。缺少有效目标的书签不可跳转，目录不会打开外部链接，也不会对扫描目录做 OCR。
- 文件不设固定字节大小上限，但导入和 PDF 渲染仍受本机可用磁盘、内存及 PDF.js 解析能力影响。每篇最多 2,000 页、2,000 万提取字符；单条高亮最多 200 个区域，适合按短段落批注。
- 搜索为文本子串匹配，忽略英文大小写，最多返回 100 条；没有语义检索或公式识别，未完成大规模文献库性能验证。
- 选文处理常见横排单栏／双栏、跨行、混合字体及上下标；复杂绕排、竖排、从右向左的文字和异常编码仍可能不准确，保存前请核对引文。
- 高亮支持缩放和 PDF 固有旋转，没有手绘或用户旋转页面功能；批注不写回 PDF，也不导入 PDF 内嵌批注供编辑。
- 笔记由用户手动编辑，没有自动翻译、Markdown 预览、云同步或多人协作。同一文献建议只在一个窗口编辑，避免并发覆盖。
