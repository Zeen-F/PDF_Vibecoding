# 纸间 Paperdesk

一个在 Mac 浏览器里使用的本地 PDF 文献工作台。文献库、PDF、双语笔记和批注均保存在本机。阅读和编辑不调用 AI 服务，也不上传论文。

## 打开

双击同目录下的 **启动纸间.command**。启动窗口会打开浏览器，并显示本地地址：

**http://127.0.0.1:4317**

保持启动窗口运行；结束时在该窗口按 Control+C。再次双击即可恢复文献库。关闭网页不会删除数据。本机已准备好运行依赖和界面，不需要再次安装。

## 五步上手

1. **导入 PDF**：点击左上角按钮，或把一个／多个 PDF 拖到页面。每份最多 50 MB。完全相同的文件自动去重；同名但内容不同的文件可同时存在。也可点击“打开阅读示例”。
2. **阅读与搜索**：左侧输入正文、笔记或批注中的关键词，点击结果跳到对应页面。支持中文、英文及跨行短语，忽略英文大小写。正文命中会标亮；搜索笔记或批注会打开对应面板。使用页码输入框或箭头翻页，可选适合宽度、80%、100%、125%、150%。窄窗口可收起右侧面板。
3. **高亮与批注**：在 PDF 中用鼠标选中文字，在底部预览核对引文，再点击“高亮并批注”。选择颜色，可附上评论。支持反向拖选和跨行选文；取消选择后会清除旧引文。右侧“批注”可以修改、删除；点击批注页码或引用回到原文。批注与原 PDF 分开保存，原文件不会被覆盖。
4. **双语笔记**：中英文各自编辑，支持输入 Markdown。停止输入约 0.65 秒自动保存，也可点击“保存”。显示“已保存到本机”表示服务端保存完成。请求失败时保留浏览器草稿，恢复连接后再次保存；请留意错误提示。
5. **导出**：点击“导出 Markdown”。工具先保存当前笔记，再下载 `.md`，包含文献标题、原始文件名、双语笔记、全部引用／评论和页码，可继续在 Obsidian 等编辑器中使用。

快捷键：**⌘K** 聚焦全文搜索。批注对话框可用 **Esc** 取消。

## 数据和备份

数据保存在本文件所在目录的 `data/`：

- `paperdesk.sqlite`：文献索引、阅读位置、笔记和批注。
- `pdfs/`：导入的原始 PDF，按内部标识命名，字节不变。
- SQLite 运行期间可能生成 `-wal`、`-shm` 辅助文件，属于数据库的一部分。

**备份时先停止启动窗口中的服务，再复制整个 `data/` 文件夹。** 恢复时先关闭服务，再将备份放回同一位置。不要在运行期间单独复制数据库主文件。

浏览器存储只是未保存笔记的应急草稿，正式数据在 `data/`。换浏览器仍可看到已保存内容。服务仅监听本机 `127.0.0.1`，同一局域网的其他电脑不能直接访问。

## 当前范围

- 面向带可选中文字层的 PDF。扫描件可阅读、写笔记，但没有 OCR，不能对图片里的文字全文检索或选文高亮。
- 暂不支持加密／权限受限的 PDF；导入时会明确提示。
- 每份最多 50 MiB、2,000 页、2,000 万提取字符。单条高亮最多 200 个区域，建议按短段落批注。
- 搜索为文本子串匹配，最多返回 100 条；没有语义检索或公式识别。大量文献的检索会变慢。
- 选文会按文字位置恢复常见横排单栏／双栏的阅读顺序，处理跨行、混合字体及常见上下标。复杂图文绕排、竖排、从右向左的文字和异常编码 PDF 仍可能识别不准确，请保存前核对引文；已有批注的引文不会被自动改写。
- 高亮按 PDF 页面归一化坐标保存，支持缩放和文档固有旋转；暂无手绘或用户旋转页面功能。
- 批注存储在文献库并导出至 Markdown，不写入 PDF；现有 PDF 内的交互批注不会被导入为可编辑批注。
- 双语笔记是手动编辑，不自动翻译；没有云同步、多人协作。建议同一文献只在一个窗口编辑，避免最后一次保存覆盖另一窗口的修改。
- 笔记可输入和导出 Markdown，当前编辑区不提供 Markdown 渲染预览。

## 开发与迁移

已在本机 Node.js 25.8.1 上验证。源码要求 Node.js 22.13+；推荐当前受支持的 Node.js LTS。新机器首次准备依赖需要联网，此后的阅读、搜索和编辑均使用本地资源。

```sh
npm ci
npm run build
npm start
```

开发界面：先运行 `npm start`，另一个终端运行 `npm run dev`。测试：`npm test`。

可用 `PORT` 修改本机监听端口，用 `PAPERDESK_DATA_DIR` 指向其他数据目录。修改端口后应访问启动窗口显示的地址。不要把数据目录设置在源码或公开静态资源目录中。

源码：`src/` 是界面，`server/` 是本地服务，`tests/` 是集成测试。`API.md` 记录接口契约。依赖锁定在 `package-lock.json`。

PDF 渲染与选文使用 [Mozilla PDF.js](https://mozilla.github.io/pdf.js/examples/)；存储使用 [Node.js SQLite](https://nodejs.org/api/sqlite.html)，界面构建使用 [Vite](https://vite.dev/guide/)。所需 PDF 字体、CMap、WASM 和 worker 随本地构建提供，不依赖在线 CDN。

示例 PDF 为本项目原创练习材料，不是研究论文或实验结果。当前示例笔记和批注用于展示工作流程，可以自行修改。

## 本次验证

当前版本 **1.0.1**。服务端测试 17/17、浏览器选文回归 17/17 通过，并在浏览器实际走通导入、跨页搜索、选文高亮、双语笔记、刷新恢复和 Markdown 下载。还检查了延迟保存竞态、90° 旋转 PDF、150% 缩放、特殊页面单位及较窄窗口。详见 `验收记录.md`。

选文回归页为 `tests/selection-harness.html`，开发服务启动后打开 `/tests/selection-harness.html`，点击 “Run selection tests”。该页面仅测试浏览器选区与布局，不访问文献库。

保存竞态的浏览器回归脚本为 `tests/notes-race.browser.mjs`，需要 Ego Lite 测试环境及单独的示例文献库；不要对自己的正式笔记直接运行该脚本。
