# 个人页面书签（1.2.0-beta.1 预览版）

在 PDF 阅读器工具栏点击「书签」，打开个人书签列表，再点击「添加当前页书签」。默认名称是「第 N 页」，可以改成章节、公式或待回访的问题。每篇文献的每个实际 PDF 页最多保存一个书签。点击列表中的名称即可跳到对应页；支持左右翻页、多页布局和上下连续阅读。

书签与 PDF 自带的章节目录分别显示，扫描件、没有目录或目录识别失败时也能添加。记录使用实际 PDF 页码，不使用书中印刷页码或目录校正偏移。

支持改名和删除。改名失败时保留输入，读回其他窗口的最新书签后，由用户核对并再次保存；不会自动覆盖他人的改名。保存或编辑书签期间，切换文献、切换仓库和退出会受到保存保护。删除书签只移除这条导航记录，PDF、笔记与批注保留。

Obsidian 模式把书签写入 `Paperdesk/Notes/<文献编号>.md` 的可读生成区和完整隐藏状态；普通文献库保存在本机数据库。关闭、重开后可以继续跳转，Obsidian 模式重建索引也能恢复。书签不写进原 PDF，不生成额外 PDF 副本。

此版本的数据库为 schema 5。升级旧库时，程序在任何建表或改表前，在本机数据目录的 `recoveries/migrations/` 创建并读回检查一致性数据库备份，包含已提交的 WAL 内容；备份失败会停止升级。仓库书签采用 v3 完整状态，旧 v1／v2 文献继续读取，成功保存时升级并保留原位或导入 PDF 来源。

升级前先正常退出并保留完整文献库备份；仓库模式同时保留整个 Paperdesk 管理目录、全部关联源 PDF 和库外数据目录。自动数据库备份不包含所有正式资料；回退旧程序须恢复升级前完整备份。原有章节目录与文字目录识别行为保留，个人书签不会改写目录或应用印刷页码偏移。
