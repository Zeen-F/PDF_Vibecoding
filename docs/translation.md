# 软件内翻译

纸间支持百度、微软 Azure Translator、DeepL，以及自定义 OpenAI 兼容接口。翻译由本机服务直接调用你配置的 API；浏览器版与 Codex 原生面板使用同一份本机配置。翻译不发起 Work／Codex 对话，不使用 Codex 模型额度；选中的文字会发送给所选服务。PDF 文件、整页内容和笔记不会随选区自动上传。

## 配置与使用

1. 打开纸间 **“翻译设置”**，选择服务，填写该服务的参数。密钥只填在软件里，不发到聊天、不写进代码。
2. 核对本机月度字符上限，点击保存。保存会启用所选服务，其他服务已保存的配置继续保留；保存不发送测试文字，也不表示外部凭据已验证。
3. 拖选带文字层 PDF 中的短段落，点击 **“翻译”** 或 **“翻译选区”**。译文显示在独立区域，可选择中文或英文，不自动加入笔记。
4. 需要更换服务时，在设置中选择已配置的服务并保存，同一服务的密钥可以留空复用。移除凭据只清除所选服务，保留其他服务及历史用量。

| 服务 | 设置参数 | 接口与计费说明 |
| --- | --- | --- |
| 百度通用翻译 | APPID、密钥、实际标准／高级套餐 | [开通说明](https://fanyi-api.baidu.com/access/0/1)：标准版每月 5 万字符，高级版个人认证后每月 100 万；超出按 49 元／百万字符计费 |
| Azure Translator | API 密钥、完整翻译接口地址、按资源要求填写区域 | [请求及认证](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/v3/translate)；默认全球接口，Azure 资源需实际选择 [F0 免费档](https://azure.microsoft.com/en-us/pricing/details/translator/)才能使用每月 200 万字符免费量 |
| DeepL | API 密钥、账户对应的免费／付费接口地址 | [认证说明](https://developers.deepl.com/docs/getting-started/auth)；当前 Developer 是总计 100 万字符试用，不按月恢复，[套餐说明](https://support.deepl.com/hc/zh-cn/articles/360021200939-DeepL-API-%E8%AE%A1%E5%88%92) |
| 自定义（OpenAI 兼容） | 完整 Chat Completions 地址、API 密钥、模型名 | 使用 [Chat Completions 格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；无需使用 OpenAI 官方服务，但你的服务必须兼容此协议。没有统一免费量，价格及权限由该服务决定 |

上述权益按 2026-10-07 官方规则核对，可能调整，以服务商控制台为准。纸间的本机字符上限是请求保护，不等于剩余免费量或账单估计；模型接口往往按 token 计费，字符数不能换算成准确费用。DeepL 和自定义的默认月度上限是本机保护值，不代表平台每月免费。

### 接口地址

- Azure 默认：`https://api.cognitive.microsofttranslator.com/translate`。区域资源可能需要区域请求头；专用资源可填写服务商给出的完整翻译路径，不能只填域名。
- DeepL：`https://api-free.deepl.com/v2/translate` 或 `https://api.deepl.com/v2/translate`，须与账户匹配。默认可依据密钥类型确定；接口选项不是在软件里升级账户。
- 自定义地址须是完整路径，例如 `https://your-api.example/v1/chat/completions`，模型名采用你在服务商处已开通的名称。程序不猜测模型、不自动选更贵的模型、不调用工具。
- 外部地址要求 HTTPS；本机兼容服务可使用 `http://127.0.0.1:端口/v1/chat/completions`。地址不能含用户名、密码、查询参数或片段。改变地址主机时必须重新填写密钥，避免将旧凭据自动发送给新服务；不跟随重定向。

## 本机用量与缓存

纸间按本机记录的已发送字符设置停止阈值，达到上限不再发送新请求；可以调低，设为 0 暂停发送。统计按北京时间自然月，使用 Unicode 字符数，并保守计入失败或超时请求。缓存命中不重新调用服务。

同一账户在其他软件、设备或密钥中的用量不在这里完整统计，服务商账单始终是最终依据。预算和缓存按服务及凭据身份分开，模型或接口路径变化不能清空当前身份的已用字符。移除后重新配置同一凭据不会清空本机累计用量；旋转密钥或账户的计费关联无法由本机自动判断。

## 数据和限制

- 各服务的凭据、参数、本机用量与有界译文缓存保存在当前文献库目录的独立 `translation.sqlite`，不改主文献库 schema 3。目录与数据库使用仅当前用户访问的权限；备份含凭据，不得上传或提交 Git。
- 设置读回只包含配置状态、必要的接口／模型参数和账号掩码，不返回密钥。插件通过面板专用工具取得展示数据，仅放在私有 `_meta`，不写入对话或模型上下文。
- 只有点击翻译才发送该次文字快照；换页、换文献或改变选区后，过期响应不能显示为新选区的结果。翻译不覆盖笔记、批注或原始 PDF。
- 百度标准单次最多 1000 字符，高级最多 6000 字符，并受 6000 UTF-8 字节保护；其他接口目前使用 10000 字符、40000 UTF-8 字节的本机请求保护。超过时请分段选取，不静默截断。平台还可能有自身的更低限制。
- 请求串行限速、设截止时间，不自动重试或切换到其他服务。使用的是受支持的 API 协议；任意供应商的其他私有协议需要另加适配，填写网址本身不能使所有接口兼容。
- 扫描件暂无 OCR，区域图片不能直接翻译。可继续框选并批注；OCR 需另行决定。
- 配置保存只证明本机写入完成。真实翻译须用有效凭据验证，错误不会改写原文。生成式模型可能出现解释或错误，译文以原文核对，不当作自动核实后的结论。

## 验证边界

自动测试使用原创文献、临时文献库和受控响应，验证各服务的请求格式、认证、解析、配置切换、缓存、预算、重启、凭据与接口边界、异常和选区竞态。模拟结果不能证明真实账户可用、真实网络或译文质量。安装与本轮结果见 [0.9.0 变更记录](history/codex-plugin-0.9.0.md)。
