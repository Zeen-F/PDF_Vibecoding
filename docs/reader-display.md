# 阅读显示设置

浏览器与 Codex 原生阅读面板提供两种翻页方式和五种页面布局。设置只影响阅读显示，不修改 PDF、笔记、批注或翻译服务配置。

## 翻页方式与页面布局

- **左右翻页**：每次显示一组页面，上一页／下一页按钮切换整组。单页时每次一页，双页时每次两页，四页时每次四页。
- **上下连续**：通过阅读区的滚动条连续浏览文献；附近页面按需加载，离开视野的页面释放显示资源。页码表示当前阅读／选区所在的实际 PDF 页。
- **页面布局**：单页、双页、四页（2×2）、六页（3×2）、九页（3×3）。页数不足时显示剩余页面；不补造空白页。

输入页码或点击目录、搜索、批注仍定位到指定的 PDF 页；多页布局同时显示它所在的一组。预览、翻译和批注使用实际选中的那一页，不把一组中的第一页当成所有选区的来源。文字批注仍要求选区在同一页内，跨页文字范围不能直接保存为一条引文。

## 缩放

- **适合宽度**：依据当前阅读区、页面列数和页间距计算宽度；大显示器上不再把显示缩放限制为 165%。左右文献栏、目录和笔记面板变化后会重新计算。
- **适合整屏**：让当前页面组的宽度和高度同时适合阅读区。切换多页布局时优先使用此模式；需要更大正文时可再选适合宽度或固定百分比。
- 固定百分比提供放大阅读；超出阅读区时可以滚动查看。浏览器百分比依据 PDF 的页面单位，原生面板百分比相对于当前适合宽度的显示尺寸；原生 PNG 接口不返回 PDF 的原始页面单位。

页面显示尺寸与底层图片／画布的像素预算分开。浏览器保留 PDF.js 文字层及页面坐标，并按资源预算调整画布像素密度；原生面板继续使用有界的本机 PNG 渲染。极大缩放不能使扫描原图产生新的细节。

浏览器的显示偏好保存在当前浏览器本机存储，不跨设备同步。原生面板在宿主允许本机存储时保留偏好，宿主隔离存储不可用时只在当前面板保留。更换文献不会改变文献归属、笔记或翻译参数。

## 阅读位置历史与来源定位

桌面版／浏览器阅读器工具栏中的两个箭头分别“返回上一阅读位置”和“前进下一阅读位置”。文献切换、页码、目录、书签、搜索与批注跳转记录实际 PDF 页；来自知识工作台的选区同时保留采集身份。重复点击同一目标不会占用新的历史位置；连续滚动只更新当前位置。返回后选择新位置（包括滚动到另一页）会清除前进分支，停在同一位置不会清除。

来源选区、来源批注和搜索结果上方提供“返回阅读”，直接回到上一阅读位置；“关闭来源定位”只移除标记并留在当前页。首次从外部链接打开、没有上一位置时不显示返回按钮。

返回／前进时，阅读器尽量恢复该历史位置最近的页内滚动位置，而不只是页首。显示位置按实际页面宽高归一化，适用于固定缩放、连续阅读和多页布局；切换尺寸后仍以对应页面为锚。它仅留在当前窗口内，刷新后的持久恢复继续使用已保存的实际页码，不更改笔记或书签格式。

窗口内最多保留 100 个位置，刷新后重新开始。页面 URL 随已确认位置更新，浏览器自身的返回仍可以回到打开来源的应用。跨文献回看继续等待笔记和阅读位置保存；未完成批注、书签或发送操作的保护保持有效。取消跳转、验证失败或较旧的响应不会前移历史游标。

批注搜索按批注 UUID 重新确认原始矩形；工作台采集使用经过清单、附件和原 PDF 校验的矩形，以蓝色框标出来源。蓝色框不会写入 PDF 或变成新批注，可点击“关闭来源定位”移除。缩放、连续阅读与多页布局仍以原始物理页面和归一化坐标为准。无效页码、陈旧哈希或缺失来源会明确报错，保留原阅读位置。

本窗口确认删除批注后，相关历史记录保留文献和实际页码，移除已删除的批注标识；当前定位提示与地址同步清理，刷新仍可打开原页。删除失败或结果未确认时保留定位状态。外部传入的失效批注链接仍会报错，不自动改成普通页码跳转。

这组历史和来源定位控制尚未扩展到 Codex 原生阅读面板。

## 验证边界

回归使用隔离文献库与原创多页 PDF，覆盖大屏宽度、布局切换、首尾页、准确跳页、连续滚动、非首页选文／框选、缩放后的批注坐标及迟到页面响应。正式文献库不用于自动测试，不发送文献或固定示例到外部翻译服务。

各次实际验证和安装状态记录在 [0.11.0 变更记录](history/codex-plugin-0.11.0.md)。

## 划词与手动选段翻译

选中词句或一段文字后点击“翻译”，核对当前选区及服务，再明确确认发送。每次只处理手动选中的内容，不自动识别或读取相邻段落，没有整页翻译入口。复杂多栏与公式附近的选文需核对预览。

## 阅读界面细化（待发布）

- 常用的页码、前后页、来源历史、缩放与区域批注留在工具栏；“显示设置”按需展开阅读方式与每屏页数，不再始终占据工具栏。Enter／Space 可打开，设置区内 Esc 或“完成”收起并返回入口焦点，点击工具栏以外也会收起
- “专注阅读”临时隐藏文献、笔记及目录侧栏；“退出专注”恢复此前开关状态，不改写侧栏持久偏好，不卸载笔记编辑器，不清空草稿。随时主动展开文献或笔记也会退出专注；书签正在保存或有未确认编辑时不能启动此模式
- 选文翻译打开后聚焦卡片，暂时收起重复的选区操作条；Esc／关闭返回仍存在的选区翻译入口；选区已清除时返回 PDF 阅读区。设置对话框独立处理 Esc，不把关闭设置误当作关闭译文。窄窗采用保留安全边距的底部卡片，内容在卡片内滚动

以上交互已增加回归脚本和静态检查；当前云环境不能启动 Chromium，实际键盘行为、遮挡与不同窗口尺寸的视觉验收仍待运行，不以构建结果替代验收。
