# 开发工作区验收 · 2026-10-05

本次将 Paperdesk 1.0.1 接续为独立开发仓库，保留产品功能和数据库结构。

## 迁移与开发准备

- 原型的 26 个源码、文档及示例文件复制后逐文件校验 SHA-256，原目录保留。生成资源、依赖和个人文献库不进入 Git。
- 已有文献库通过 SQLite 一致性备份迁入；校验数据库完整性、记录一致性及原 PDF 字节和 SHA-256。切换前正常关闭旧服务并保留完整快照。
- 正式服务从新工作区运行，正式数据保存在 `data/`；开发默认使用独立的 `.local/dev-data/`。
- 私人来源、迁移清单、数据库快照和原聊天接续信息仅保存在本机 `.local/migration-20261005/`，不上传仓库。
- 提供单命令开发启动、Node 版本约定、锁定依赖、编辑器工作区、贡献流程、Issue/PR 模板和 GitHub Actions 检查。
