## 恢复范围

- 插件版本为 0.7.0，原生资源为 `ui://paperdesk/reader-v7.html`。保留 8 个公共文献工具及 6 个面板专用工具。

- “交给 Codex”只共享选区，不自动提问；明确说“记下来”等才追加笔记。笔记的版本校验、草稿保护、幂等追加和安全刷新继续保留。

- 已移除此前两份专用 ChatGPT 浏览器配置，不保留其中登录资料；纸间插件的文献库绑定配置保留。正式文献库中原本没有 `chatgpt-jobs` 目录，未执行任务目录清理。

## 使用边界

普通阅读仍在本机处理。主动共享或发送的选区会进入当前对话及模型请求；切页、撤回共享或关闭面板不能收回已经发送到对话的内容。宿主缺少消息或图片能力时保留可复制提问及按需读取共享截图的说明，不将坐标回执当作图片已发送。

原生笔记需手动保存，关闭面板可能丢失未保存草稿。AI 回答默认只在对话中，只有明确要求后才追加到指定文献的笔记。
