# Paperdesk 1.2.0-beta.2

本版增加 Windows x64 的使用、开发与桌面发布支持，修复 Windows 上的 PDF 资源路径、升级备份刷新和测试进程退出问题。保留 macOS Apple Silicon 入口与原有阅读、批注、笔记和 Obsidian 功能。

## 下载与使用

- **Windows x64：** 下载 `Paperdesk-1.2.0-beta.2-win-x64.zip`，完整解压到可写目录，双击 `Paperdesk.exe`。无需安装 Node.js；运行期间保留整套解压文件。桌面包未签名，首次运行按 Windows 的安全提示核对来源。
- **Apple Silicon Mac：** 下载 `Paperdesk-1.2.0-beta.2-mac-arm64.dmg`，将 Paperdesk 拖到“应用程序”。也提供 ZIP。应用未经过 Apple 签名或公证。
- **浏览器版：** 下载 `Paperdesk-1.2.0-beta.2-browser.zip`，安装 Node.js 24+ 后执行 `npm ci --omit=dev`、`npm start`，访问本机 `http://127.0.0.1:4317`。Windows PowerShell 使用 `npm.cmd`；也可双击 `启动纸间.cmd`。
- 校验文件分别为 `SHA256SUMS-win`、`SHA256SUMS` 和 `SHA256SUMS-browser`。没有自动更新。

## Windows 适配

- PDF 字体、字符映射及 WASM 资源路径统一处理盘符、中文、空格和分隔符。
- 统一 Windows 短路径和目录联接的实际路径，避免同一知识库因不同路径写法被判断为不同实例。
- 修复 SQLite 升级备份在 Windows 上刷新文件时的权限错误，保留迁移前一致性备份与读回检查。
- Windows 使用 Ctrl 搜索快捷键和对应菜单；关闭窗口等待保存后退出，macOS 保留隐藏窗口惯例。
- 保留森林、暖砂、雾蓝、夜读四套界面皮肤，切换与重启后的主题记忆纳入浏览器回归。
- 开发库与正式库隔离。启动器和测试通过 IPC 关闭本次服务，回收本次浏览器、桌面进程和临时库。
- Windows 桌面库默认位于 `%APPDATA%/Paperdesk/library/`，Obsidian 库外缓存位于 `%APPDATA%/Paperdesk/vault-cache/`。
- 浏览器 ZIP 构建不再依赖外部 `zip` 命令。CI 增加 Windows 检查；发布流程分别验收 Windows ZIP 解压副本和 Mac DMG 安装副本。

## 数据与兼容

沿用 beta.1 的 schema 5 和 v3 知识库 Markdown，不新增数据库版本。更新前正常退出应用并备份完整文献库；个人 PDF、笔记和密钥不包含在发布包中。菜单可连接已有独立库或 Obsidian 知识库，不自动搬迁 Mac 资料。多个设备不要同时编辑同一文献。

## 验证范围

发布流程要求 API、生产构建、浏览器回归、源码桌面和实际发布包的导入、批注、笔记、Obsidian、书签及九组保存可靠性检查通过，随后才生成发布草稿。Windows 无文件符号链接权限时，仅对应能力用例跳过，目录联接检查仍执行。具体通过结果以该标签的 GitHub Actions 运行和附带检查摘要为准。

真实翻译服务凭据、Codex 宿主完整对话、断电恢复和多设备写入一致性不在本次发布验收范围。没有新增 OCR、云同步或 AI 服务。
