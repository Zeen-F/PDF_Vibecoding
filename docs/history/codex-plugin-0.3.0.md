# Paperdesk 插件 0.3.0：选区讨论与笔记刷新

2026-10-06，用户确认纸间原生面板可以在 Codex 中打开，并授权继续优化与对话的交互。

## 改动范围

- 插件版本更新为 0.3.0，原生资源改为 `ui://paperdesk/reader-v3.html`，避免混用旧面板缓存。
- 选区预览增加“解释选区”“提炼要点”“自定义提问”。用户点击后，通过 `ui/message` 把问题和当次确认的选区快照发送到当前对话。
- 保留“交给 Codex”的原有含义：只共享选区，不自行发起回答。讨论不会自动写笔记。
- 消息携带文献、PDF 页码及文字／区域 PNG 快照；后来换页、撤回或会话过期不会把问题的来源改成其他页面。已发送到对话的内容无法通过撤回当前共享收回。
- 宿主消息或图片能力不足时，明确说明尚未发送并提供可复制提问；截图可按用户要求由普通工具读取仍在共享的会话，不把坐标当作图像。
- 原生笔记区支持“刷新笔记”，并处理当前文献的聊天追加结果。未保存草稿及正在保存的内容不得被刷新替换；用户明确要求记录时仍使用版本校验和幂等追加。

没有新增 OCR、自动翻译、整书提取、独立模型 API、云端资料库或自动保存聊天回答的功能。PDF 与笔记仍使用已有本机库；用户确认发送的选区和问题会进入 Codex 对话及模型请求。

## 使用提醒

解释和要点默认显示在当前对话。只有用户明确说“记下来”等才追加笔记；可通过“刷新笔记”读回结果。有草稿先保存，冲突时核对最新笔记后手动合并。原生面板的笔记需要手动保存，关闭可能丢失未保存草稿。

保留 [0.2.0 历史记录](codex-plugin-0.2.0.md)，其中截至当时尚未确认的宿主打开能力已由本轮用户反馈补充；该历史记录不替代 0.3.0 的消息流程验收。
