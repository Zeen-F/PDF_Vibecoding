# 1.1.0-beta.4 macOS 桌面预览版

首次发布采用本版，软件行为沿用 [1.1.0-beta.3](1.1.0-beta.3.md) 的桌面、数据、复制和选区共享修复。之前三个版本均为未发布构建候选。

浏览器验收在真实拖选结束后等待预览与实际 DOM 选区完全一致，再读取引文或确认共享。拖选过程会按动画帧更新预览，立即读取可能取得中间的半句；此调整保持原先完整引文和 API 精确断言，不改变选文算法、范围或测试截止时间。

发布包含 macOS Apple Silicon DMG、ZIP 和 SHA256SUMS。安装、数据位置及未签名说明见 [桌面预览版](../desktop-release.md)；以本版本地安装后检查及远端工作流结果确认交付。
