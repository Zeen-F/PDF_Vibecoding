# 1.0.1 历史验收摘要

原交付日期：2026-10-05。本文从原型交付记录提炼，用于保留已有修复背景；以下均是迁入正式开发工作区之前报告的结果，不能当作当前分支或 CI 的通过证明。原交付材料保留在本机，个人定位信息不进入版本库。

## 原型报告的验证

- 服务端测试 17/17 通过，生产构建成功。
- 实际走通 PDF 导入、跨页搜索、原文选取和批注、双语笔记、刷新恢复及 Markdown 下载。
- 核对原 PDF 字节读回、SHA-256 去重、中文及英文跨行搜索、异常输入和重启持久化。
- 检查延迟保存请求的先后顺序、切换文献时的旧保存队列，以及导出前保存最终内容。
- 浏览器检查 150% 缩放、PDF 固有 90° 旋转、窄窗口和本地资源加载。

## 1.0.1 选文修复

曾复现页脚先于正文写入 PDF 内容流，造成拖选标题时夹入页脚。修复以视觉位置组织文字层阅读顺序，并按文字节点的实际字符边界提取引文。

历史浏览器选文回归报告 17/17 通过，覆盖字符偏移、正反向选择、跨行、混合字体与空格、中英文、上下标、单双栏及通栏标题／页脚、容器边界、空选区、矩形处理和旋转。另报告完成特殊 `/UserUnit=2` 的文字层对齐、取消后清除旧选区，以及批注弹窗缩放时保持引用的实际检查。

## 证据范围

这些结果来自当时的原型环境，没有完成大规模文献库压力测试，也没有证明兼容所有真实论文版式、编码、复杂绕排或从右向左的文字。扫描件没有 OCR。
