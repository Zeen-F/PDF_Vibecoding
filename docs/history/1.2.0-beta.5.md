# Paperdesk 1.2.0-beta.5

本次为 Windows x64、Apple Silicon macOS 和本机浏览器的预发布版本。只以 Release 页面实际提供且通过校验的资产为准，不覆盖旧版本。

## 更新

- 可选山岚 V2 外观：紧凑书架、晨间／月下场景、按标题快速定位，以及鼠标／键盘调宽文献栏。弹窗支持方向键、Enter、Esc 和 Tab／Shift+Tab 焦点循环，关闭后返回入口。
- 显示设置集中到工具栏弹层，完善窄窗口布局；专注阅读保留草稿，来源跳转后可回到原页与窗口内位置。修复快速来源跳转早于滚动采样时返回旧位置的问题，并加入延迟动画帧的确定性回归。
- 翻译只处理用户手动选择的词句或段落，发送前核对；切换服务配置、语言或失败重试均重新确认。不提供整页翻译，不自动扩展或连续发送选区。
- MCP 搜索默认只查标题；正文、笔记和批注依赖本机明确授权、范围、有效期与预算。
- 保留云盘 PDF 的有界重试和完整性校验；修复 Windows 路径规范化及 inode 故障注入测试。更新安装、阅读、保存恢复、Codex 与资料交换说明。

## 使用与升级

Windows 完整解压 `Paperdesk-1.2.0-beta.5-win-x64.zip` 后打开 `Paperdesk.exe`。Mac 将 DMG 内的完整应用复制到“应用程序”，也提供应用 ZIP。浏览器 ZIP 需要 Node.js 24+。校验文件为 `SHA256SUMS`、`SHA256SUMS-win` 和 `SHA256SUMS-browser`。

默认入口保留原外观。桌面添加 `--shanlan-daily` 使用新外观并沿用原配置；`--shanlan-preview` 使用独立预览配置。浏览器在本机地址后添加 `/?visual=shanlan`。密度与场景不改写保存的主题。

升级前正常保存、退出并备份完整资料。替换完整应用，不搬动 PDF 或知识库；原 schema 5 与 Obsidian Markdown 规则不变。插件不会自动安装、绑定或扩权。本版没有自动更新。

## 验证与限制

本地 Windows API 检查 354 项通过、7 项按条件跳过，生产构建、完整 Playwright Chromium 浏览器回归以及隔离 Electron 的选文、保存、导出、退出重开和失败保护通过。发布流程还会对 Windows ZIP、macOS DMG 安装副本及浏览器 ZIP 执行各自的隔离成品检查，最终结果以对应 Actions 和发布资产为准。

新增 V2 和来源返回专项回归通过。修复宿主模拟测试的时钟覆盖问题：父页面虚拟时钟未同步推进不透明 iframe 的计时器。消息超时回归改用真实的 15 秒产品截止时间，检查超时状态、耗时边界、迟到回执和不重复发送；不改动产品超时逻辑。

测试使用合成材料。真实外部翻译 API、当前 Codex 宿主内嵌面板视觉验收、原生 macOS 人工体验及约 6px 极小字号选文未在本轮验证。Windows 正常字号的原生鼠标选文已验证。模拟模型与宿主协议结果不能代替真实服务验收。

Windows 包未签名；macOS 包没有 Developer ID 签名或 Apple 公证，不保证下载后的 Gatekeeper 放行。遵循系统提示，不关闭整体安全保护。暂无 OCR、内置云同步或多设备并发编辑保证。
