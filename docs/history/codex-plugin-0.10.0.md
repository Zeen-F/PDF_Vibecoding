# Paperdesk 插件 0.10.0：配置内测试翻译

翻译设置新增用户主动测试入口，支持已有四种服务。用当前候选参数或保存凭据发送固定英文示例，展示译文、耗时及错误类别；不保存、启用草稿或发送文献，不写笔记、模型消息或上下文。

真实请求绕过缓存，仍保留用量、限速、截止时间及凭据主机绑定。测试失败保留草稿，修改、切换服务或关闭后不展示旧结果。主库 schema 3 与翻译侧库 schema 2 均不变，原生共 18 个工具、10 个 app-only，资源为 `reader-v10`。

本轮使用独立工作区、临时资料库和受控接口响应，不使用正式文献或真实密钥。

- Node.js 24.19.0 下最终 `npm run check` 退出码 0：105 项 API／MCP／运行时检查、生产构建、17 项真实 DOM 选文及完整浏览器工作流通过。
- 翻译后端 25 项检查通过，包含原 18 项和新增草稿试译、固定示例、四服务协议、缓存绕过、限额与失败用量、重启、独立配置／启用状态保留、队列截止时间和错误类别脱敏。队列回归等待完整请求体实际到达，不依赖固定调度延迟。
- MCP 16 项通过，试译只返回私有 `_meta.translationTest`，后端不可信错误消息安全降级，既有接口错误契约保留。原生 13 组与浏览器 7 组翻译回归通过，覆盖草稿、已保存密钥复用、失败保留、编辑／切服务／关闭后的迟到保护、四服务、笔记及模型上下文不变。
- 本轮核对森林与夜读窄窗的测试结果、原生窄窗显示；截图使用原创隔离内容并关闭动画，保持在本机忽略目录。
- 已安装并启用 0.10.0；安装回执路径的 7 个缓存文件与源码逐字节一致，实际缓存启动器 SDK 读回版本、18 个工具／10 个 app-only、`reader-v10`、test 操作和严格 CSP。
- 更新前正常停止已核实的旧实例并复制完整文献库，备份与新版启动后读回一致：三份原始 PDF、主库记录、既有翻译侧库（若有）均保留，主库 schema 3 与完整性／外键检查通过。插件配置仍指向原工作区。正式库只做备份和读回，不用于测试、不自动发送固定示例。
- 真实用户凭据连接仍由用户在软件主动点击测试。受控响应只能证明流程与协议处理，不证明用户账户可用或译文质量。
