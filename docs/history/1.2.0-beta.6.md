# Paperdesk 1.2.0-beta.6

普通桌面入口现在读取当前配置目录的 `appearance.json`，其中 `{"visual":"shanlan"}` 启用既有山岚 V2。缺失、无效或其他值沿用默认外观；原有 `--shanlan-daily` 和隔离预览参数仍有效。不会选择另一资料库、搬动资料或改变插件权限。

这是启动偏好兼容修复，未重做山岚界面。升级时保存并正常退出后替换完整应用，保留原配置目录及资料库。Windows ZIP、Mac ARM64 DMG/ZIP、浏览器 ZIP 和 SHA256 清单以本次 Release 实际资产为准。浏览器入口仍使用 `?visual=shanlan`。

自动验证包括偏好读取边界、原生普通入口重开后的山岚参数、原资料库身份和笔记保留。远端构建及安装包验证结果以本次 Actions 为准。测试只使用合成资料；Mac 预览包仍未进行 Apple 公证，请遵循系统安全提示。
