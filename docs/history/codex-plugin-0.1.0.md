# Paperdesk 插件 0.1.0 验收

2026-10-05，在 Mac 本地工作区完成。

## 已验证

- Node.js 24.21.0 运行 `npm run check`：67 项 API/MCP/runtime 测试、生产构建、17 项真实 DOM 选文回归和完整浏览器流程全部通过。新增浏览器流程覆盖主动文字/PNG 共享、多窗口、清除选区、外部笔记刷新、保存竞态、旧草稿冲突、独立恢复位置、历史草稿和并发归档。
- 本机 Codex CLI 回读 `paperdesk@paperdesk-local` 0.1.0 为 installed/enabled。安装缓存的 7 个文件与源码逐字节一致；通过真实 SDK client 启动缓存 launcher，发现 8 个工具并成功连接现有文献库。
- 默认既有库的受控自动启动成功。它复用已绑定的 `data/`，未创建替代库；不匹配服务/库、自定义端口和缺少既有文件的保护另经隔离测试。
- 现有扫描书籍通过真实阅读页框选后点击“交给 Codex”，安装后的 MCP 工具返回独立 PNG image block。点击前上下文没有选区，取消后恢复为空；未执行 OCR 或向正式笔记写入测试文字。
- 原始 PDF、raw 笔记字段、批注与阅读页码的前后比对全部一致。个人文献和截图证据仅保存在本机忽略目录，不进入 Git。

## 尚未验证

MCP Apps 原生面板的资源和消息协议已测，但当前 Codex 自身窗口禁止自动化操作，不能确认其原生入口、内嵌阅读器或模型上下文显示。已安装文献工具和普通本机阅读页可以独立使用；原生面板保持实验性。

扫描区域是图片共享，不是文字识别。插件没有云同步、自动整书提取、PDF 内嵌批注或独立安装包。安装缓存依赖本机工作区及其依赖，移动工作区须重新核对绑定。

使用和限制见 [Codex 插件说明](../codex-plugin.md)。
