# Paperdesk 插件 0.4.0：准备交给普通 ChatGPT

2026-10-06，用户希望把阅读问题交给普通 ChatGPT，避免由当前 Codex 对话回答。本版增加独立的材料准备入口，保留既有 Codex 分享和提问功能。

## 改动范围

- 插件版本更新为 0.4.0，原生资源使用 `ui://paperdesk/reader-v4.html`。
- 原生面板与浏览器阅读器增加“交给 ChatGPT”：准备用户问题、文献标题、PDF 页码及所选文字，允许核对后复制。
- 扫描区域导出预览对应的精确 PNG，不导出整页、不进行 OCR。原生面板使用宿主 `ui/download-file`；无能力、拒绝或未完成时，引导到浏览器同页重新框选导出。下载请求被接受与文件实际落盘分别核对。
- “打开 ChatGPT”只打开固定 `https://chatgpt.com/`，地址不含提问参数。用户确认普通 Chat 模式后自行粘贴、附图并发送；回答自行贴回笔记。
- 准备流程不调用 `ui/message`、`ui/update-model-context` 或模型请求。准备文本不含内部会话／文献标识、本机工具操作指令、笔记或未选页面内容。
- “解释选区”“提炼要点”“自定义提问”继续明确面向当前 Codex 对话；“交给 Codex”仍然只共享。只有用户明确要求记录时，Codex 才追加笔记。

没有新增模型 API 密钥、自动发送／读回 ChatGPT、自动保存回答或云同步。普通 Chat 仍受账号套餐和所选模型限制；ChatGPT Work 与 Codex 共享用量，不能把切换到 Work 当作用量分离。依据 [官方模式说明](https://learn.chatgpt.com/docs/use-chatgpt) 和 [官方用量说明](https://learn.chatgpt.com/docs/pricing)（2026-10-06 查阅）；本项目未核验个人账号计费。

浏览器文字准备测试使用真实鼠标拖选经过末尾字形再到同行空白，严格对照 DOM 选文、预览及提问文本；该操作在 DPR 1／2／1 的三次针对性检查及最终完整检查中通过。检查使用原创材料与隔离文献库，不能替代真实宿主剪贴板、文件落盘或普通 ChatGPT 回答的人工验收，个人账号计费也未核验。

本轮未重启正式服务、未迁移数据库或 schema，也没有读取或写入正式 PDF／笔记。正式库连接核验仅调用状态、空参数打开阅读器及 UI resource 读回，原库保留。升级备份留在忽略的 `.local/`，旧版插件缓存保留；个人资料、截图及本机配置不进入仓库。

## 使用提醒

复制失败时可在准备文本框中手动复制。原生图片下载不支持或被拒绝时，在浏览器同页重新框选，核对图片后再附到 ChatGPT。打开网站不会自动选择模式或发送消息；手动发送后的内容进入所选对话，取消纸间选区不能收回该对话里的材料。原生笔记需要手动保存，浏览器笔记按既有保存流程处理。
