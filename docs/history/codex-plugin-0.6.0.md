# Paperdesk 插件 0.6.0：专用 ChatGPT 连接与继续提问

2026-10-07，默认自动问答改用纸间管理的专用 Chromium，新增连接控制与已完成回答的追问。当前记录描述实现边界；本轮验收结果逐项补充，不沿用 0.5.0 的检查结果。

## 改动范围

- 默认无需独立 EGO Lite。纸间按需打开专用浏览器，首次登录、验证码和用户控制由用户在连接窗口处理，回纸间明确继续；发送前仍核对普通 Chat／Latest／Extra High（xhigh），不自动降级。
- “连接 ChatGPT”显示服务返回的状态，并提供打开连接窗口、关闭连接、刷新状态。窗口可用不代表已登录；执行中的任务阻止关闭连接。
- 已完成回答可继续提问：新请求绑定父任务，沿用原文献／页码／选区，由服务端加入先前问答，在新专用页发送；不是复用原 ChatGPT 网页会话，客户端不上传任意旧答案。先前问答最多 6 组、JSON 上下文最多 100,000 个 UTF-16 单元，超限拒绝而不截断。
- 原生预览默认显示 ChatGPT 的解释、提炼与自定义问题预设；预设只填问题，确认后才发送。当前 Codex 对话讨论和共享保留在默认折叠的可选区。回答只读，不自动写笔记。
- 资源升级到 `ui://paperdesk/reader-v6.html`，20 个工具中 12 个为 app-only。任务和连接结果分别保留在 `_meta.chatgptJob`、`_meta.chatgptConnection`，普通 ChatGPT 流程不调用 `ui/message` 或注入 Codex 上下文。
- 专用登录配置默认位于 `~/.config/paperdesk/chatgpt-browser/`，独立于正式文献库，不读取或复用日常 Chrome／EGO 配置。显式设置 `PAPERDESK_CHATGPT_ENGINE=ego` 才选择旧执行器；没有自动回退。

## 当前边界

关闭预览或阅读面板不取消已启动任务，已发送问题不能撤回。连接关闭在执行中被拒绝；停止服务会关闭专用浏览器，并保守处理未确认任务，不自动重新发送。网页／面板新实例暂不自动恢复旧任务显示列表。

登录配置、任务日志、输入、回答与区域 PNG 属于本机个人资料，不进入 Git。原 PDF、笔记和数据库 schema 不因连接及追问功能改变。自动检查使用临时配置和替代执行器，不以测试为理由读取日常浏览器配置或发送真实问题。

[0.5.0 历史记录](codex-plugin-0.5.0.md) 保留旧 EGO 路径的实际问答证据，不能据此认定本版专用连接、追问或安装已经通过。
