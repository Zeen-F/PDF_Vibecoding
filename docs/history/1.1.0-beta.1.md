# 1.1.0-beta.1 macOS 桌面预览版

将原先需要安装 Node.js、保持终端运行并打开浏览器的阅读流程，提供为内置运行环境的 macOS Apple Silicon 应用。此未发布构建候选包含 DMG、ZIP 和 SHA256SUMS；源码版入口仍保留。首次发布采用 [1.1.0-beta.2](1.1.0-beta.2.md)。

## 实现

- Electron 44.6.0 独立窗口复用既有阅读界面与本机服务，仅监听回环地址。单实例启动；关闭窗口先保存并隐藏，退出应用先确认笔记保存再关闭自有服务，不终止外部服务。
- 稳定用户数据目录与应用文件分离。菜单可打开已正常停止、schema 3 的完整已有库，记录、PDF 和笔记继续位于原目录；无自动迁移、移动或替代库。端口占用时保留占用者并选择本机可用端口，已绑定健康服务仅按资料库身份复用。
- 保存失败取消退出并保留草稿。切库和退出期间锁定编辑；关闭数据库前等待已接收的 PDF 导入与目录任务，渲染子进程使用 Electron 自带 Node 模式。
- 安装包采用明确文件范围，不收录个人文献库、数据库、环境文件、密钥或验证截图；图标为原创 SVG，构建产物不进入版本控制。
- GitHub 工作流在 arm64 Mac 上完成应用检查、源桌面检查及打包后检查，版本标签匹配时创建草稿预发布；手动运行仅保存构建产物。

## 本次本地自动检查

2026-10-08 在 Apple Silicon Mac 上使用隔离临时库检查：

- `npm run check`：130 项测试通过，生产构建和完整浏览器回归通过，包含真实选文、多页阅读、区域批注、笔记冲突与插件协议流程。
- 源桌面、打包 `.app` 和从实际 DMG 复制出的 `.app` 均通过桌面验收：真实 PDF 导入／渲染、鼠标选文、高亮评论、笔记保存、Markdown 文件读回、立即退出前的笔记刷新、重开恢复、原始 PDF 哈希一致、单实例与窗口隐藏。
- 保存失败保留窗口／草稿，选错库不创建文件，切库过程中键盘输入不会进入旧编辑区；已有文献库切换及重开后记录与 PDF 保留。
- 内置 Node 24.21.0 的 SQLite 与原生 canvas 可运行；PDF 页面图片在打包后的渲染子进程中生成。桌面渲染器启用 sandbox 和 contextIsolation，未启用 Node integration。
- DMG 验证、只读挂载、Applications 链接与应用复制通过；ZIP 压缩结构检查通过。安装包目录检查未发现个人资料库、数据库或环境文件，两个安装包生成 SHA-256 校验清单。
- 生产依赖审计为 0 条已知漏洞；开发打包工具不进入应用依赖目录。

桌面测试使用受控的原生对话框返回值及保存目的地，读写和退出在真实 Electron 窗口中执行；测试不访问正式文献库，也不使用真实翻译密钥。

## 视觉检查与边界

检查了真实应用中原创示例的阅读页面、中文界面、文字高亮、批注卡片和导出完成提示，未发现遮挡或明显排版异常。

本版未做 Apple 开发者签名或公证；首次从网络下载的系统确认流程仍需遵循 macOS 提示。没有验证 Intel Mac 或其他平台安装包，没有自动更新，没有以此次检查代替 Codex 宿主的实际问答或真实翻译 API 验收。远端 CI 与 Release 是否成功应以对应本次运行和发布页面为准。
