# 1.2.0-beta.3 本机 Windows 交付

2026-10-10。本版把已合并的知识工作台发送功能纳入 Windows x64 ZIP，保持 schema 5、现有 Obsidian Markdown 格式及文献资料位置。当前记录是本机构建和验收，不表示 GitHub Release 已发布，也不表示 macOS 包已更新。

与知识工作台 `0.1.0-alpha.2` 在开发目录之外、临时合成 Obsidian 库中启动两个真实 Electron 成品，完成以下检查：

- 从实际 PDF 第 2 页选择文字、第 3 页框选图片，填写想法并发送。
- 模拟回执丢失后使用相同请求重试，导出包及 PNG 校验一致且不重复。
- 关闭纸间后由工作台导入两个交换包，保留原图；重新扫描不重复收集。
- 工作台绑定重新启动的纸间服务，来源按钮经桌面接口返回文献地址；隔离浏览器实际显示原 PDF 第 3 页。
- 工作台内编辑导入笔记、保存并重开，材料和修改仍在；纸间关闭时明确提示离线，原材料仍可查看。
- 原 PDF 校验值不变，临时库和本次测试进程结束后清理。

系统默认浏览器打开接口另有实际调用；Chrome 控制连接不可用，未将其窗口观察记为通过。页码与正文显示由隔离浏览器验证。验收没有个人 PDF、真实 AI 调用、iCloud 同步或 Codex 原生阅读面板按钮。

可重放的跨产品检查位于知识工作台仓库的 `scripts/test-packaged-paperdesk.mjs`。纸间提供生产代码与合成 PDF 夹具；工作台脚本只运行已安装 EXE，不从源码启动两个产品服务。本机摘要集中在 `.local/windows-verification.json`，构建为 `release/Paperdesk-1.2.0-beta.3-win-x64.zip` 与 `release/SHA256SUMS-win`。
