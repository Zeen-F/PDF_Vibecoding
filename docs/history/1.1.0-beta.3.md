# 1.1.0-beta.3 macOS 桌面预览版

首次发布使用本版，包含 [桌面安装包](../desktop-release.md) 和 [纯文本复制权限](1.1.0-beta.2.md)。之前两个版本为未发布构建候选。

修复点击“交给 Codex”后共享状态可能随下一帧消失的竞态：浏览器在指针或键盘释放时会重新读取同一选区，原实现生成新对象并撤销对旧对象的共享。现在文字、文献、页码和归一化区域不变时保留原选区身份；真实选区、文献、页面或布局变化仍按原规则取消共享，不自动发送新选区。

浏览器及真实桌面流程在明确共享后触发无内容变化的键盘释放并等待两帧，再检查界面仍处于共享状态、API 保留完整原句。页面隐藏或离开时明确撤销共享，恢复显示不会自动重新共享；后续翻页继续验证共享被清除。沿用隔离文献库、安装包与保存验证，最终远端构建结果以本版工作流为准。
