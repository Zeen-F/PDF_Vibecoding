# 1.2.0-beta.1 变更与升级说明

本版把 Obsidian 仓库和个人页面书签纳入公开预览版本，保留已有 PDF 阅读、选文批注、布局、章节目录、笔记、翻译及可选 Codex 插件。桌面安装包面向 Apple Silicon Mac，仍未经过 Apple 开发者证书签名或公证，没有自动更新；本机浏览器包需要 Node.js 24+。这是预览版，不是稳定版或全平台支持声明。

## Obsidian 作为文献仓库

- 连接已有 Obsidian 知识库后，侧边栏默认显示知识库内 PDF；点击后原位只读打开，不移动、复制或改写这些源文件。
- 外部 PDF 可以选择导入或拖入；副本存入 `Paperdesk/PDFs/`，外部原文件保留。相同内容沿用已关联文献及批注。
- 文献正文、批注和书签保存到 `Paperdesk/Notes/<UUID>.md` 的可读内容与完整管理状态；`Library.md` 保存分类和主题。索引、翻译设置、临时解析文件及恢复资料留在知识库外。
- 正文可以在 Paperdesk 或 Obsidian 编辑。外部变化自动读回；冲突暂停自动保存，只有副本写入并读回成功才确认保存在 `Notes/Conflicts/`。手工比较并合并正文，受损文件或保存失败时保留草稿。
- 枚举 PDF 仅提供文件列表，不自动关联、提取正文或生成笔记。已有源文件移动、改名或校验变化时停止读取，不猜测新位置或自动绑定。生成区与管理状态不一致、已建立库缺少 `Library.md` 时拒绝继续读写并保留原文。

旧独立文献库仍可使用，不自动搬迁到知识库；旧 alpha 预览版的原位文献和导入副本保持兼容。知识库规则及冲突处理见 [Obsidian 仓库说明](../obsidian-vault.md)。

## 个人页面书签与目录兼容

工具栏「书签」支持添加当前页、改名、删除和跳转；每篇文献每个实际 PDF 页最多一条。书签关闭、重开后保留，仓库索引重建也能恢复；不改写原 PDF。

个人书签使用实际 PDF 页码，独立于 PDF 自带章节目录和文字目录识别，不应用印刷页码偏移。原有左右／上下阅读、多页布局、目录折叠与筛选继续使用。改名和删除具有版本校验，保存失败保留输入；切文献、切仓库和正常退出沿用保存保护。详见 [书签说明](../bookmarks.md)。

## schema 5 与 v3 Markdown

主库升级为 **schema 5**，新增个人页面书签。对已存在的旧数据库，程序先检查已建立结构，在任何建表或改表前用 SQLite 一致性机制备份到数据目录的 `recoveries/migrations/`，包含已提交 WAL 内容；读回检查备份完整性和原版本并刷新到磁盘。备份失败停止升级，之后的结构迁移在事务中完成，失败回滚。更高版本数据库不会降级，也不会将损坏的已有表或书签初始化为空内容。

桌面「打开已有文献库…」先只读校验完整 schema 4／5 库；schema 4 库随后启动时备份并升级。schema 3 或更早的新选择库先通过本版浏览器／源码服务升级，停止并核对后再选择。默认库和已记住库仍在启动时升级。

仓库旧 **v1／v2** 完整 Markdown 可读，成功保存时写入 **v3**，保留原位 PDF 路径或 UUID 导入副本、自定义属性、旧批注及重试／阅读顺序记录。v3 保存个人页面书签；不支持该格式的旧程序不能直接打开。

升级前正常退出并备份完整独立文献库；仓库模式备份完整 Paperdesk 管理目录、全部关联源 PDF 和库外数据目录，备份整个知识库更方便。自动数据库快照不包含所有 PDF、Markdown 和翻译设置。回退须恢复升级前完整资料，不能只降数据库版本或保留新格式 Markdown。具体步骤见 [桌面升级说明](../desktop-release.md#升级到-120-beta1)。

## 验证范围与限制

本次本机完成 295 项接口检查、生产构建及完整浏览器回归。真实 Apple Silicon Electron 源码和打包应用完成基础流程、各 9 组保存可靠性，以及 Obsidian 原位 PDF／外部导入、个人书签保存、正常退出和重开跳转检查；DMG 挂载后复制到隔离安装目录也完成基础及仓库书签验收。干净浏览器 ZIP 独立安装生产依赖后完成两种模式的阅读、真实选文、保存、导出与重启，并从正式 Markdown 重建仓库索引。测试使用隔离合成资料，不使用正式个人文献库。

各阶段独立记录，匿名下载校验及远端 CI／发布工作流以本次执行结果为准；源码结果不能代替安装包或远端结果，历史 alpha 检查不计入本次结果。工作流配置和 Release 链接本身不表示远端执行或发布已成功。

本版没有 OCR、云同步服务、多设备全局锁、移动端 Paperdesk 或 PDF 内嵌批注编辑。同一篇文献错开写，外部同步完整落地后刷新再换设备。多个窗口的阅读位置仍没有全局排序。复杂 PDF 选文和目录识别需保存前核对；真实 Codex 宿主中的完整插件流程需单独验收，模拟协议检查不替代宿主显示与回答。
