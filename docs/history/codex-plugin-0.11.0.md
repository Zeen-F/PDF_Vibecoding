# Paperdesk 插件 0.11.0：大屏与多页阅读

阅读工具栏提供左右翻页／上下连续阅读，单页、双页、四页、六页和九页布局，以及适合宽度／适合整屏。宽度依据真实阅读空间计算，移除浏览器 165% 显示上限和原生面板固定最大显示宽度。固定缩放仍可滚动查看。

连续阅读使用附近页面加载与资源释放，页码、目录、翻译、批注与共享快照继续绑定实际 PDF 页。显示方式改变会取消旧选区；跨页文字选区不作为一条引文保存。笔记保护、翻译凭据与用量、本机访问边界保持现有契约，主库 schema 3 与翻译侧库 schema 2 不变。

原生协议版本为 0.11.0，资源为 `ui://paperdesk/reader-v11.html`。仍有 18 个工具、10 个 app-only；翻页与预加载不自动注入模型上下文。显示偏好与已知限制见 [阅读显示设置](../reader-display.md)。

## 本轮验证

本轮使用 Node.js 24.19.0、独立工作区和隔离资料库；没有使用正式 PDF 或真实翻译凭据进行测试。

- 最终 `npm run check` 退出码 0：105 项 API／MCP／运行时检查、生产构建、17 项真实 DOM 选文回归和完整浏览器工作流通过。
- 新增原创 23 页 PDF 验证：2560×1440 大屏宽度填满与缩小窗口、五种布局及尾组、紧凑页间距、精确跳页、横向／纵向／长页面混排、连续滚动及附近页面资源释放、显示偏好刷新恢复。
- 浏览器检查真实拖选第 5 页文字与扫描区域、保存坐标及来源页、跨页 Range 拒绝、模式／布局／文献切换后的旧选区清除。原有文字边界、缩放、区域草稿、笔记队列、翻译及分类流程继续通过。
- 真实 MCP 与 opaque sandbox 检查原生多页预加载仍使用 app-only 私有展示数据、最多两个在途渲染请求、准确滚动／输入页码、第 5 页截图提问及第 6 页主动替换选区；既有消息仍保留第 5 页的冻结来源。
- 截图使用原创隔离材料，核对宽度填满、紧凑四页／尾组、非首页文字及区域预览。截图只保存在本机忽略目录。
- 本机已安装并启用 0.11.0，更新资源 URI 区分旧面板缓存。安装后的插件清单、缓存文件与真实 SDK 工具／资源读回单独核对。
- 更新前正常停止已核实实例并完整备份资料库，备份读回一致；新版启动后原始 PDF、主库记录、翻译侧库凭据与用量的校验保持一致，schema 与完整性检查通过。插件 profile 仍指向原工作区及同一资料库。
- 正式资料库仅做更新备份、校验和配置状态读回，不用于测试，不在本轮自动调用真实翻译服务。
- GitHub CI 以本次提交的远端 Checks 为准。上述自动宿主检查不能替代真实 Codex 客户端中的用户确认；更新后需关闭旧面板再打开。
