# Paperdesk 插件 0.8.0：文献文件夹与四套皮肤

本轮在隔离开发工作区新增本机文献整理与外观偏好，继续使用当前 Work／Codex 对话讨论确认过的选区。[0.7.0 恢复记录](codex-plugin-0.7.0.md) 保留原文，历史通过结果不计入本轮验收。

## 改动范围

- 插件版本为 0.8.0，原生资源为 `ui://paperdesk/reader-v8.html`，共 17 个工具：8 个公共文献工具和 9 个面板专用工具。
- 浏览器和原生面板均提供单层文件夹、全部文献／未分类筛选、新建、重命名、确认删除，以及拖动和“移动到”选择。删除文件夹使其中的文献回到未分类，不删除 PDF、笔记或批注。
- 分类筛选和移动只更新文献元数据，保持当前阅读页和笔记草稿。原生面板依次读完每页最多 50 条的文献分页，再显示完整分类；最多载入 10000 篇，超过或中途失败会明确报错，不展示误导性的部分分类。
- 森林、暖砂、雾蓝、夜读四套皮肤保存到本机文献库，重新打开时恢复；其他已打开窗口需刷新读回。主题覆盖阅读器界面、笔记区和弹窗，PDF 页面原色不变。
- 原生新增 `paperdesk_reader_library`、`paperdesk_reader_organize`、`paperdesk_reader_theme`，结果只通过 `_meta.library` 返回组件。分类和外观操作不发送对话消息或共享模型上下文，仍无直接网络请求、外部资产或嵌套网页。
- 翻译需求留待与用户讨论；本轮没有翻译按钮、翻译 API 或新增外部服务。

## 数据迁移

首次启动前，须正常停止旧服务并完整备份文献库；不要在运行中只复制 SQLite 主文件。schema 3 增加 `folders`、单行 `library_preferences` 及 `documents.folder_id`，结构和版本在同一事务提交；旧文献默认为未分类、皮肤默认为森林。已有 PDF、笔记原始字段、批注和阅读位置保留，失败回滚，更高版本数据库拒绝降级。

回退程序时应恢复升级前的完整库，不能手工删表、删列或只改版本号。本轮开发和自动测试使用隔离库，正式库升级、备份与读回须单独记证据。

## 保留的边界

单层文件夹不支持嵌套或多标签；移动文献只改变数据库归属，不改原始 PDF 路径或内容。分类和主题不是跨设备云同步，也不保证已打开的其他窗口实时更新。

选区预览、主动发送问题、扫描区域共享、笔记版本冲突保护及明确要求后追加笔记继续沿用。回答默认留在当前对话，原生笔记仍需手动保存。
