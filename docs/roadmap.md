# 后续候选工作

以下是讨论优先级，不是已实现功能、排期或交付承诺。每项开始前应先明确场景、范围和验收条件，再建立 Issue。

| 优先级 | 候选事项 | 目标与建议验收 |
| --- | --- | --- |
| P1 | 备份与恢复操作 | 减少手工操作；在隔离库中验证备份、恢复及 PDF／笔记／批注一致性 |
| P1 | 真实 PDF 兼容样例集 | 收集可合法共享的单双栏、复杂字体、页面单位、扫描图像和目录排版样例，记录支持范围并补回归 |
| P1 | 保存冲突提示 | 明确多窗口编辑时的行为，避免静默覆盖；先定义冲突策略 |
| P2 | 阅读体验与可访问性 | 根据实际反馈改善键盘操作、窄窗口和错误恢复，以具体操作任务验收 |
| P2 | 检索性能基线 | 先测量不同文献规模的耗时与内存，再决定是否引入全文索引 |
| P2 | 数据结构迁移维护 | schema 3 已加入分类及库偏好；已有事务迁移；后续变更继续补兼容、备份恢复与回滚验证 |
| P2 | 目录映射兼容性 | 扩充复杂目录、分段页码与罗马编号测试，保持未确认目标不可跳转；当前不含 OCR |
| P3 | 笔记 Markdown 预览 | 保持原始文本和导出一致，明确渲染安全与编辑体验 |

0.9.0 的软件内文本选区翻译采用百度通用 API，配置和边界见 [软件内翻译](translation.md)。其他翻译服务、全文翻译及扫描件 OCR 翻译仍需单独讨论。OCR、云同步、多人协作、PDF 内嵌批注与跨平台安装包也需要单独讨论，尚未加入开发计划。现有 Work／Codex 选区讨论按插件边界维护。
